# Fantasy Basketball Weekly Report 🏀

An automated fantasy basketball analytics and reporting project for a private 12-team Yahoo Fantasy Basketball league, **League of Extraordinary Men**.

## Overview

This project aims to generate weekly power rankings, matchup recaps, and entertaining league commentary using statistics retrieved from the Yahoo Fantasy Sports API.

The goal is to combine data-driven analysis with engaging sportswriting to create a weekly report that league members look forward to reading.

## Planned Features

- **Weekly Power Rankings:** Rank all 12 fantasy teams based on performance, projected strength, and recent trends.
- **Matchup Recaps:** Summarize weekly head-to-head results and important category battles.
- **Weekly Awards:** Recognize standout performances, major upsets, close losses, and notable roster moves.
- **Transaction Analysis:** Highlight impactful trades and waiver-wire acquisitions.
- **Historical Rankings:** Track each team's movement throughout the season.
- **AI-Generated Commentary:** Produce entertaining, statistics-based recaps with humor and friendly competition.

## Yahoo Fantasy API Integration

The application is intended to use read-only Yahoo Fantasy Sports API access to retrieve:

- League information and scoring settings
- Team rosters and standings
- Weekly matchups and category results
- Player statistics
- League transactions

The application will not modify fantasy rosters, submit trades, or perform
